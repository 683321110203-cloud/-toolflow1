# ToolFlow - ระบบยืมคืนอุปกรณ์

- `frontend/` : หน้าเว็บ (index.html, app.js, style.css, logo.png, gear.svg)
- `backend/`  : เซิร์ฟเวอร์ + ฐานข้อมูล (ใส่ไฟล์ backend ของโปรเจกต์ที่นี่)

หน้าเว็บเรียก REST API ที่ `/api/...` จึงต้องรัน backend ด้วย
GitHub Pages รันได้เฉพาะหน้าเว็บ (static) ไม่รัน backend
